# 简历要点

## 中文

**CampusFlow｜线上学习管理系统｜独立开发**

- 设计并实现课程、教师、学生、选课和授课关系的桌面管理系统，覆盖检索、增删改查、选课与成绩分析完整流程。
- 基于 Python、Tkinter、SQL Server 与 Matplotlib 构建多视图管理界面，通过触发器实现删除级联和课程完成积分自动更新。
- 将数据库凭据迁移至环境变量，修复建库初始化脚本，并补齐依赖清单、项目文档和 CI 语法检查。

## English

- Built a desktop learning-management system covering courses, teachers, students, enrollment, teaching assignments, and grade analytics.
- Implemented multi-view CRUD and Matplotlib reporting with Python, Tkinter, and SQL Server, including trigger-driven cascade cleanup and credit updates.
- Hardened setup with environment-based credentials, a corrected schema script, reproducible dependencies, documentation, and CI syntax checks.

不添加未经测量的用户量、覆盖学校数量或效率提升指标。
